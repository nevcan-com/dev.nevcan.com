# Git Fundamentals

**Internal training at Doğuş Teknoloji** · slides:
[nevcanuludas.github.io/git-fund](https://nevcanuludas.github.io/git-fund/)

A hands-on introduction to Git that I gave as an internal trainer: from the first commit to
branches, merging and rebasing, and how Git stores things underneath.

|                  |                                                                                  |
| ---------------- | -------------------------------------------------------------------------------- |
| Quick start      | init, config, status, add, reset, ignore, commit, squash, push, pull, stash, log |
| Branches         | merge and rebase, tags, HEAD                                                     |
| Under the hood   | Git objects, SHA-1 and the .git folder                                           |
| Working together | GUI tools, remote repositories, forks and pull requests                          |

The `git lg` alias from the slides is still the one I use every day. It works in this site's
terminal too: try `git lg`.
