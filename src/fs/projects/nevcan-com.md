# nevcan.com

One person, several sites. Each subdomain is one field I work in:

| Site                                       | What                           |
| ------------------------------------------ | ------------------------------ |
| [dive.nevcan.com](https://dive.nevcan.com) | Diving: education, exploration |
| **dev.nevcan.com**                         | Software: you are here         |

This one is built with [Astro](https://astro.build) and React. The editor, the file tree and the
terminal are all one small React component; every file is a Markdown file, and each one is also a
plain HTML page, so search engines (and people who'd rather not type) can read it.
