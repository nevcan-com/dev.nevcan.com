# GUE TR Hub

**Since 2026**

A private reference hub for GUE instructors and candidates in Türkiye: course notes, schedules,
drills, standards and e-mail templates, shared by link. Every page sits behind Google sign-in.

Built as a small static site generator (JSON, Pug and SCSS), with Firebase Authentication,
Firestore and Storage, and security rules covered by tests.
