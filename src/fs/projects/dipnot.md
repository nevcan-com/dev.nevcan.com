# Dipnot

**Since 2025** · technical co-founder · [dipnot.app](https://dipnot.app)

A Turkish publication on diving, underwater photography and marine life: articles and news for
readers, and a community around them. Members save articles, follow the categories they care
about and get notifications. The name means "footnote", with a pun on _dip_, the seabed.

|                    |                                                                          |
| ------------------ | ------------------------------------------------------------------------ |
| Mobile app         | React Native with Expo, for readers, on the App Store and Google Play    |
| Editorial platform | Next.js, TypeScript and Firebase: publishing, advertising and operations |
| Website            | Eleventy, on GitHub Pages                                                |
| Back end           | Firebase: one Firestore database, Cloud Functions, App Check             |
